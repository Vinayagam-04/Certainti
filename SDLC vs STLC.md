# **SDLC vs STLC: Simplified**

## **SDLC (Software Development Life Cycle)**  
1. **Goal**: Build functional software from concept to deployment.  
2. **Phases**: Requirements → Design → Coding → Testing → Deployment → Maintenance.  
3. **Focus**: Entire development process (planning, coding, releasing).  
4. **Team**: Developers, designers, project managers.  
5. **Outcome**: A working software product ready for users.  

---

## **STLC (Software Testing Life Cycle)**  
1. **Goal**: Find and fix defects to ensure software quality.  
2. **Phases**: Test Planning → Test Design → Environment Setup → Execution → Closure.  
3. **Focus**: Testing only (no coding/design).  
4. **Team**: QA engineers, testers.  
5. **Outcome**: Bug-free, validated software ready for release.  

---

### **Key Difference**  
SDLC builds the product; STLC ensures it works as intended.
